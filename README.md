## Persistencia de datos con Hibernate y PostgreSQL

♠ * Hibernate es un framework ORM ( Mapeo Objeto -Relacional) de código abierto para Java. Simplifica la conexión a bases de datos mapeando clases (objetos) de Java a tablas de bases de datos y tipos de datos de Java a tipos de datos SQL. En lugar de escribir largas consultas SQL, los desarrolladores pueden usar las API de Hibernate o HQL (Hibernate Query Language) para realizar operaciones CRUD.
○ * Asigna objetos Java a tablas de base de datos, reduciendo la necesidad de usar SQL manualmente.
♠ * Admite operaciones CRUD a través de las API de Hibernate o HQL.
○ * Gestiona automáticamente las conexiones a la base de datos, el almacenamiento en caché y la gestión de transacciones.

♠ * PostgreSQL es un potente sistema de bases de datos objeto-relacionales de código abierto que utiliza y amplía el lenguaje SQL.
○ * Combinado con numerosas funcionalidades que permiten almacenar y escalar de forma segura las cargas de trabajo de datos más complejas
